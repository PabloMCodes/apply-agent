# Common SWE profile fields

Reviewed public employer application forms on September 13, 2026. This is a small
US-focused sample, not a universal application schema. Field wording/options vary.

| Actual form | Observations incorporated |
| --- | --- |
| [Xometry, Staff Software Engineer](https://job-boards.greenhouse.io/xometry/jobs/5139094007) | Contact details, location, LinkedIn, work authorization, sponsorship, start availability, compensation expectations, voluntary gender/ethnicity/veteran/disability fields |
| [Zimperium, Software Engineer](https://jobs.lever.co/zimperium/b425b2ad-cad4-4c35-a720-9b41274f4861/apply) | Current company, GitHub, hybrid attendance, US eligibility, sponsorship; its Race dropdown includes ethnicity categories |
| [MX, Senior Software Engineer II](https://job-boards.greenhouse.io/mxtechnologiesinc/jobs/4385268009) | School, degree, discipline, education years, sponsorship, voluntary self-identification |

The profile uses concise standard labels and explicit saved choices. Employer-specific
referral, previous-employment, and motivation questions stay on each application.
Citizenship/status is included at the user's request and is separate from authorization;
it is not present on every SWE application. The profile is not an official government
self-identification form and does not replace employer instructions or definitions.

Separate ethnicity and race answers are never combined automatically. A separate
combined-category preference must be supplied for those forms. Blank, No, and Prefer
not to disclose remain distinct. Demographic and eligibility mappings are suggestions
for review; they are never inferred from a name, location, resume, or another status.

Resume extraction is local and conservative: header contact details and links, named
technologies, and clearly labeled education facts. Existing field values are preserved.
A scanned PDF may have no extractable text; ambiguous layouts require manual entry.
